# صيدلي — Pharma Delivery

تطبيق جوال أصلي مفتوح المصدر لتوصيل الأدوية والمنتجات الصحية، مبني باستخدام **Expo 54 + React Native + TypeScript**. صُمم هذا المستودع كنقطة انطلاق عملية يمكن للصيدليات والمطورين تخصيصها للسوق المحلي.

## الحالة الحالية

نسخة MVP قابلة للتشغيل تتضمن:

- متجر عربي متجاوب باتجاه RTL.
- بحث وتصنيفات: الأدوية، الفيتامينات، العناية بالبشرة، الأم والطفل.
- بطاقات منتجات وتفاصيل المنتج.
- سلة مشتريات مع تعديل الكميات وحذف المنتجات.
- احتساب رسوم التوصيل وإعفاء الطلبات من 100 ر.س فأكثر.
- إنشاء الطلب عبر API مشترك مع عنوان التوصيل وقائمة المنتجات.
- شاشة متابعة الطلبات من قاعدة البيانات مع حالات الطلب.
- تسجيل الدخول والخروج عبر OAuth مع حفظ الدور (`user` / `admin` / `captain`).
- حفظ السلة محلياً، مع مزامنة الطلبات عند الاتصال بالخادم.
- خادم tRPC وقاعدة بيانات MySQL وترحيلات Drizzle وصلاحيات محمية.

> **تنبيه صحي:** هذا المشروع واجهة تقنية للتوصيل وليس بديلاً عن الطبيب أو الصيدلي. يجب تطبيق متطلبات الترخيص والتحقق من الوصفات وحماية بيانات المرضى قبل تشغيله تجارياً.

## التشغيل محلياً

### المتطلبات

- Node.js 22 أو أحدث
- pnpm 9 أو أحدث
- Expo Go أو محاكي Android/iOS

### الأوامر

```bash
pnpm install
pnpm dev
```

للتشغيل على جهاز محدد:

```bash
pnpm android
pnpm ios
pnpm qr
```

للفحص:

```bash
pnpm check
pnpm test
pnpm lint
```

## بنية المشروع

```text
app/
  (tabs)/index.tsx       # المتجر والرئيسية
  (tabs)/cart.tsx        # السلة وتأكيد الطلب
  (tabs)/orders.tsx      # الطلبات السابقة
  (tabs)/profile.tsx     # الحساب والإعدادات
  product/[id].tsx       # تفاصيل المنتج
data/catalog.ts          # كتالوج المنتجات التجريبي
lib/store.tsx            # حالة السلة والطلبات
lib/store-utils.ts       # منطق التسعير القابل للاختبار
tests/                   # اختبارات Vitest
server/                  # خادم tRPC والمصادقة الجاهز للتوسعة
drizzle/                 # مخطط قاعدة البيانات والترحيلات
```

## خارطة الطريق المقترحة

1. ربط كتالوج الصيدليات والمخزون بقاعدة البيانات.
2. إضافة رفع الوصفة الطبية والتحقق اليدوي من الصيدلي.
3. ربط الخرائط ومناطق التوصيل وموقع المندوب.
4. تفعيل إشعارات Push لحالات الطلب.
5. إضافة الدفع الإلكتروني بعد إعداد مزود دفع مرخص.
6. تفعيل إدارة المستخدمين والكباتن من لوحة الإدارة.
7. تطبيق متطلبات الخصوصية وحماية البيانات في بلد التشغيل.
